# E-commerce-Sales-Dashboard
Interactive E-Commerce Sales Dashboard built with Power BI.

## Project Overview
This Power BI project presents an interactive E-Commerce Sales Dashboard designed to analyze sales performance, orders, products, categories, sales channels, order status, and monthly trends.

## Dashboard Highlights
- **Total Sales:** 3.44M
- **Total Profit:** 1.15M
- **Total Orders:** 500
- **Total Quantity:** 1K
- Sales analysis by category
- Order status distribution
- Sales by sales channel
- Top 5 products by sales
- Monthly sales trend
- City-based filtering using slicers

## Key Visuals
1. Total Sales, Total Profit, Total Orders and Total Quantity KPIs
2. Total Sales by Category
3. Total Orders by Order Status
4. Total Sales Amount by Sales Channel
5. Top 5 Products by Sales
6. Total Sales by Month
7. City slicer for interactive filtering

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis
- Excel / tabular data source

## Purpose
The dashboard was created as a portfolio project to demonstrate practical skills in Power BI, data visualization, KPI reporting, filtering, and business-oriented data analysis.
